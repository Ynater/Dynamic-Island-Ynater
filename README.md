# 🏝️ Islet

**Islet** — это стильный виджет в стиле Dynamic Island для Windows, созданный на Electron. Он висит сверху экрана, расширяется при наведении и предоставляет быстрый доступ к таймеру, погоде, управлению громкостью и настройкам.

## ✨ Возможности

- 🎨 **Кастомизация**: 12 цветовых тем (по умолчанию минималистичный белый).
- ⏱️ **Умный таймер**: Настраиваемое название задачи и время (1–120 минут) с уведомлениями в стиле iOS.
- 🌤️ **Погода**: Реальные данные без API-ключей (Open-Meteo), сохранение выбранного города.
- 🔊 **Управление громкостью**: Ползунок, который меняет **реальную системную громкость Windows** (через Python + `pycaw`).
- ⌨️ **Горячие клавиши**: 
  - `Ctrl + Space` — Показать/скрыть виджет.
  - `Ctrl + 1/2/3/4` — Быстрое переключение вкладок.
- 🖥️ **Адаптивный дизайн**: Плавные анимации, чёрное свечение при приближении курсора, отсутствие полос прокрутки.
