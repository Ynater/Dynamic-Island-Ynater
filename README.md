# 🏝️ Ynater v1.6.1

Самый функциональный Dynamic Island виджет для Windows с открытым исходным кодом.  
Ynater превращает ваш рабочий стол в умную панель управления, объединяя эстетику macOS с мощью Windows.

## ✨ Возможности

### 💻 Система и мониторинг
- **📊 Монитор ресурсов:** Живой спарклайн CPU, RAM, температура процессора/GPU (NVIDIA), аптайм.
- **💾 Диски и процессы:** Использование дисков (C:/D:/E:), топ-5 процессов по нагрузке.
- **🌐 Сеть:** Тест скорости интернета по клику, мониторинг upload/download.
- **🔋 Батарея:** Уровень заряда и статус для ноутбуков.
- **💱 Финансы:** Курсы валют ЦБ РФ (USD/EUR) и криптовалют (BTC/ETH) в реальном времени.

### 🎨 Визуал и персонализация
- **💧 Жидкие края:** Эффект gooey-анимации при взаимодействии.
- **🪟 Матовое стекло:** Glassmorphism размытие фона под островком.
- **🌌 Звёздное небо:** Анимированный ночной фон.
- **🎭 Компаньон:** 8 уникальных скинов (Котик, Робот, Лиса, Призрак, Капибара, Панда, Инопланетянин, Сердечко).
- **😊 Настроение:** Компаньон реагирует на время суток и события системы.
- **🎨 Кастомизация:** 12 цветов акцента, масштаб острова 80–130%.

### 📝 Заметки и продуктивность
- **Markdown:** Поддержка жирного, курсива, списков и заголовков.
- **Теги:** Организация через #работа, #личное и др.
- **Архив:** Старые заметки не удаляются, а уходят в архив.
- **Поиск:** Мгновенный фильтр по тексту и тегам.
- **Экспорт:** Сохранение заметок в TXT/PDF.
- **Статистика:** Счётчик слов и символов.
- **Цели на день:** Список задач с прогресс-баром.
- **Перевод:** Интеграция с API для перевода текста.

### 📋 Умный буфер обмена
- **Закрепление 📌:** Важные элементы (пароли, ссылки) всегда наверху.
- **Категории:** Автоопределение типа (текст, ссылка, email, код).
- **Поиск:** Мгновенная фильтрация истории.
- **Перевод:** Перевод скопированного текста в реальном времени.

### ⚙️ Поведение и удобство
- **🎮 Игровой режим:** Автоскрытие в играх и полноэкранном режиме.
- **👁️ Приватность:** Скрытие на скриншотах и поверх выбранных программ.
- **🔕 Не беспокоить:** Таймер отключения уведомлений (30мин/1ч/2ч).
- **⌨️ Индикаторы:** Статус Caps Lock и раскладки (RU/EN) прямо на острове.
- **⚡ Быстрый запуск:** Discord, Telegram, Chrome, VS Code одним кликом.
- **❓ FAQ:** Встроенная справка по использованию.

## 🚀 Установка

1. Перейдите в раздел [Releases](https://github.com/Ynater/ynater/releases).
2. Скачайте последнюю версию `Ynater-Setup-1.6.1.exe`.
3. Запустите установщик и следуйте инструкциям.

### Горячие клавиши
| Комбинация | Действие |
|-----------|----------|
| `Ctrl + Space` | Показать / Скрыть островок |
| `Ctrl + Shift` | Переключить раскладку (индикатор на острове) |
